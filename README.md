# Anel de Letras

Um anel de diamante em 3D desenhado com as letras de um nome. O aro é escrito com um nome e a pedra com outro. Dá zoom até conseguir ler as letras.

Abra `index.html` no navegador. Não precisa instalar nem compilar nada.

- `?nome=Ana&pedra=Joao`: nomes pela URL (o botão "copiar link" gera isso)
- Roda do mouse / pinça: zoom no ponto apontado
- Arrastar: girar · Shift ou botão direito + arrastar: mover · duplo clique: voltar
